## Problem

Participants need a way to request mentor support and access event information.

## Implementation

The inspected mentor service persists a request to Firestore and attempts an administrator notification through OneSignal.

## Results

VERIFIED: the request and notification code paths exist. The checked-in service uses placeholder notification configuration, so working delivery is not established.

## Limitations

Privileged notification credentials should not be embedded in a client application. No live backend, delivery, or production use was tested.
