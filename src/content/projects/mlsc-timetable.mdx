## Problem

Institutional spreadsheets often encode schedules through merged cells and visual layout rather than normalized data.

## Implementation

The parser uses Excelize, discovers batch headers, reads merged-cell day ranges, and extracts subject, faculty, room, and time information using layout heuristics.

## Results

VERIFIED: spreadsheet-to-lecture parsing is implemented. Compatibility with arbitrary timetable formats is not established.

## Limitations

Fixed header rows and heuristic room/faculty detection make the parser format-dependent. Unsupported layouts can be skipped rather than diagnosed explicitly.
