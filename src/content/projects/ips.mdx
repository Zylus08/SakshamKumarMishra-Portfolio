## Problem

Forecasting comparisons need consistent data splits, horizons, metrics, and compute conditions.

## Implementation

The inspected experiment runner registers PatchTST, TimesNet, NHITS, Prophet, and Chronos wrappers, sets NumPy and PyTorch seeds, and calls split/window utilities across a dataset registry.

## Results

VERIFIED: model registration and experiment orchestration are implemented. This audit does not reproduce the model rankings.

## Limitations

The runner contains absolute local dataset paths. Portable dataset provisioning, wrapper parity, and split consistency need verification before comparative performance claims.
