## Problem

Short-range links have bounded packet sizes and intermittent connectivity. MeshNet explores an offline communication stack around those constraints.

## Architecture

The Kotlin multi-module layout separates transport, routing, protocol, storage, cryptography, and application features. The BLE layer includes fragmentation and reassembly components.

<Diagram steps="Payload|BLE fragments|Reassembly" />

## Implementation

The inspected fragmenter emits a four-byte header containing flags, an eight-bit sequence number, and a transfer identifier. It splits payloads to a configured size and handles single-fragment messages separately.

## Results

VERIFIED: application-layer fragmentation and the module interfaces exist. Device-to-device operation, battery behavior, mesh scale, and cryptographic security were not independently validated in this review.

## Limitations

Physical-device tests are needed across MTUs, packet loss, sequence wraparound, and reconnects. The presence of X3DH and ratchet modules is not a security certification. The inspected LICENSE contains Apache 2.0 text, while API license detection was inconclusive.
