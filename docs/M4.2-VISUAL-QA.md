### 2. Typography, Headings & Mathematical Notation

1. **Heading Hierarchy:**
   - Case study pages use clean `H1` (page heading), `H2` (primary technical sections), and `H3` (subsystem breakdowns).
   - All `H2` and `H3` headers receive automated ID slugification (`rehypeArticleHeadings`), enabling one-click deep anchor linking with smooth scroll-margin offset (`scroll-margin-top: 110px`).
2. **KaTeX Equation Formatting:**
   - KaTeX equations are rendered server-side via `rehype-katex` and `remark-math`.
   - Display equations ($$...$$) are wrapped with safe overflow boundaries, preventing mobile viewport blow-out.
   - Tested equations:
     - AXIOM: Three-valued logic assertions.
     - PRAXIS: Handle Reference Model tuple $\langle \text{targetId}, \text{generation}, \text{targetType}, \text{offset} \rangle$.
     - FORGE: Amdahl's Law speedup formulation $S_{\text{max}} = \frac{1}{(1 - f) + \frac{f}{\infty}}$ and gradient chain rule.
     - VECTRA: Memory bandwidth throughput model and integer dot-product scaling.
3. **Code Blocks & Pre-formatted Text:**
   - Syntax-highlighted code blocks use monospace typography (`var(--font-mono)`).
   - Code blocks preserve indentation, scroll horizontally within container margins, and include copy buttons.

### 4. Theme & Accessibility Audit (Dark / Light Mode)

1. **Contrast Ratio Compliance:**
   - Dark mode (`--bg: #101114`, `--surface: #191b20`, `--ink: #f1eee8`, `--accent: #cf9874`): Text-to-background contrast ratio $> 11:1$ (exceeds WCAG AAA standard of 7:1).
   - Light mode (`--bg: #f3f0e9`, `--surface: #e9e5dc`, `--ink: #25262b`, `--accent: #925936`): Text-to-background contrast ratio $> 10.5:1$ (exceeds WCAG AAA).
2. **Keyboard Navigation & Focus Rings:**
   - Every interactive element (nav links, collection cards, career tabs, filter chips, download buttons) features explicit focus outline styling:
     ```css
     button:focus-visible, a:focus-visible {
       outline: 2px solid var(--accent);
       outline-offset: 5px;
     }
     ```
3. **Screen Reader Accessibility:**
   - Decorative elements (`dot`, arrows, asterisk, chess grid) carry `aria-hidden="true"`.
   - Complex interactive elements carry appropriate `role="tablist"`, `role="tab"`, `aria-selected`, and `aria-label` attributes.
