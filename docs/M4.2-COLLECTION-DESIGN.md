### Executive Summary

Milestone 4.2 introduces the **"Built from First Principles — Four explorations into computational infrastructure"** editorial showcase collection. The collection bridges four independent systems engineering repositories into a unified narrative progression:

$$\text{SQL Execution (AXIOM)} \longrightarrow \text{Language Interpretation (PRAXIS)} \longrightarrow \text{Neural Training (FORGE)} \longrightarrow \text{Model Inference (VECTRA)}$$

### 1. Conceptual Narrative and Computational Stack

The four projects represent progressive tiers of the computational infrastructure stack:

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        THE COMPUTATIONAL STACK                         │
├─────────────────┬──────────────────┬─────────────────┬─────────────────┤
│    01 / AXIOM   │   02 / PRAXIS    │   03 / FORGE    │   04 / VECTRA   │
├─────────────────┼──────────────────┼─────────────────┼─────────────────┤
│ Storage & Query │ Execution Engine │ Training Infra  │ Inference Eng   │

│ Relational SQL  │ Safe C++ AST     │ Native AVX2     │ Clean-room GGUF │
│ Out-of-core     │ Handle Model     │ Zero-Mask       │ Zero-Graph      │
│ Grace Hash Join │ Deterministic    │ Amdahl Forensics│ AVX2 INT8 GEMV  │
```

#### Crucial Editorial Guardrail: Independence Without Monolith
The portfolio explicitly disclaims that these four projects form a single monolithic software application. They are independent open-source repositories sharing a common design philosophy of clean-room engineering, hardware-conscious implementation, and empirical verification. A prominent editorial disclaimer informs visitors:
> *"These four systems are standalone, independent repositories sharing a common design philosophy of first-principles construction and empirical verification; they do not constitute a single monolithic product."*

### 2. Component Architecture

The collection is implemented in `src/components/first-principles-collection.tsx` as a pure server/client component adhering to Next.js 15 standards:

1. **Header Block:**
   - Visual badge: `<i className="dot" /> SPECIAL EDITORIAL COLLECTION`
   - Eyebrow: `BUILT FROM FIRST PRINCIPLES`
   - Primary Heading: `Four explorations into computational infrastructure.`
   - Editorial Framing: Explaining the conceptual progression across system layers.
2. **Horizontal Conceptual Pipeline Strip:**
   - Displays numbered pipeline nodes: `01 SQL Execution → 02 Language Interpretation → 03 Neural Training → 04 Model Inference`.
   - Uses monospace typography (`micro`), accent badges, and subtle arrows to visually communicate progression.
3. **Responsive 2×2 Card Grid:**
   - Four interactive cards linking to `/projects/axiom`, `/projects/praxis`, `/projects/forge`, and `/projects/vectra`.
   - Each card features:
     - Header: Step ID (`01`–`04`), Subsystem Layer, Domain.
     - Title: Project name in serif typography (`var(--font-serif)`).
     - Summary: 2–3 line technical description.
     - Metrics Bar: 3-column data grid showcasing verified quantitative proofs.
     - Proof Point: Standout verified empirical result.
     - Tags: Subsystem and technology badges.
     - Action: Explicit "Read case study →" text link.

### 3. Visual Styling and Design Token Integration

All styling integrates seamlessly into the existing portfolio palette (`src/app/globals.css`):
- **Backgrounds:** `var(--surface)` for cards; `var(--bg)` for inner metric boxes.
- **Borders:** `var(--line)` default with smooth hover transition to `var(--accent)`.
- **Accents:** Warm ochre `var(--accent)` (`#cf9874` dark / `#925936` light) highlighting IDs, values, and links.
- **Typography:**
  - Headers: `var(--font-serif)` for editorial elegance.
  - Body: `var(--font-sans)` for crisp reading comfort.
  - Telemetry & Labels: `var(--font-mono)` with `0.07em` letter spacing.
- **Motion:** Micro-elevation on card hover (`transform: translateY(-2px)`) with subtle border color transitions.

---

### 4. Responsive Viewport Strategy

- **Desktop ($\ge 901\text{px}$):**
  - Two-column balanced grid (`grid-template-columns: repeat(2, minmax(0, 1fr))`).
  - Generous card padding (26px) with 3-column metric grids.
- **Tablet / Mobile ($\le 900\text{px}$):**
  - Single-column linear layout (`grid-template-columns: 1fr`).
  - Pipeline strip wraps gracefully while preserving directional continuity.
  - Metric boxes retain 3-column density or stack comfortably without overflow.

---

### 5. Role-Based Navigation Placement

To respect the portfolio's primary audience (quantitative finance and systems recruiters):
- **Location:** Section 02 (`02 / THE ENGINEER`) of the homepage.
- **Ordering:** Positioned directly following the 7 curated homepage projects (`tradecore`, `flowstate`, `risklab`, `roadvision`, `hydra-stream`, `project-janus`, `thermodynamic-evolution`).
- **Recruiter Experience:** A quantitative recruiter landing on the homepage immediately encounters `TradeCore`, `FlowState`, and `RiskLab` first. Scrolling further introduces the deep systems foundations in the First Principles Collection, demonstrating end-to-end computational mastery from SQL query planners to quantized LLM inference runtimes.
