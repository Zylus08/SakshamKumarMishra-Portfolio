## Findings fixed during verification

The initial complete browser run had **96 passes and 10 failures**. It is not reported as a pass. Four failures were the new anchor/table checks on desktop and mobile. Six mobile accessibility failures identified overflowing code or mathematical regions without keyboard focus (including one aggregate route test). The initial run took 18.4 minutes, with an unusually long table wait; its failures remain failures regardless of host timing.

Corrections:

- Combined global scroll padding and article scroll margin placed anchor targets below the active-section threshold. Article margins now complement the existing global padding.
- Literal HTML tables in MDX bypass the generic table renderer override. An explicit `TableScroll` component now wraps both evidence tables; it uses a labeled, focusable scroll region and requires no MDX JavaScript expressions.
- A post-KaTeX HTML transform adds keyboard focus and labels to display equations and code blocks, preserving narrow-screen horizontal scrolling.

The production build and full suite were rerun after these fixes; the complete final run passed without retries or exclusions. Logs remain local and ignored: `.tmp/m31-build-final.log`, `.tmp/m31-unit-final.log`, `.tmp/m31-browser-final.log`. The initial browser log is `.tmp/m31-browser.log`. Twelve screenshots (about 1.61 MB total) accompany the visual report. `git diff --check` passed; its only output was Windows line-ending notices.
